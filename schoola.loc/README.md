# Лабораторная работа PHP: дата и приветствие

Это сайт из архива `schoola.loc.zip`. Готовый проект нужно положить в `C:\OSPanel\home\schoola.loc` и открыть в браузере по адресу `http://schoola.loc/`, когда Open Server запущен.

## Где находится код

Главный файл для защиты работы — **`index.php`**. В нём выполнены все три упражнения. `style.css` отвечает за оформление, `.osp/project.ini` выбирает PHP 8.3 в Open Server. Остальные PHP-страницы (`about.php`, `contact.php`, `table.php`, `calc.php`) взяты из архива и не относятся к этим трём упражнениям.

## Упражнение 1: текущая дата

Перед заголовком «Зачем мы ходим в школу?» добавлен `<blockquote>`. В первой версии упражнения там можно было написать:

```php
<?php echo strftime('Сегодня %d-%m-%Y'); ?>
```

`strftime()` берёт дату с компьютера, где работает PHP. `%d` — день, `%m` — номер месяца, `%Y` — год. `<blockquote>` выделяет дату на странице. Во второй версии мы заменили этот вывод более подробным, как требует следующее упражнение.

## Упражнение 2: дата через переменные

В начале `index.php`, до HTML, создаются переменные:

```php
$day = @strftime('%d');
$mon = @strftime('%B');
$year = @strftime('%Y');
```

`$day` содержит день, `$mon` — русское название месяца, `$year` — год. `setlocale(LC_ALL, 'russian', ...)` включает русскую локаль. В `<blockquote>` команда `echo` выводит фразу из этих частей. Внизу страницы `<?= $year ?>` вставляет актуальный год вместо постоянного `2021`.

На Windows русская локаль Open Server выдаёт месяц в кодировке Windows-1251, а страница использует UTF-8. Поэтому `iconv()` переводит название месяца в UTF-8, чтобы вместо русских букв не появились непонятные символы. Знак `@` перед `strftime()` скрывает предупреждение о том, что эта функция устарела в PHP 8.3; функция пока работает и оставлена ради задания.

## Упражнение 3: приветствие

`$hour = (int) @strftime('%H')` получает текущий час от 0 до 23. `(int)` превращает строку в целое число. Дальше цепочка `if / elseif / else` выбирает текст:

| Часы | Приветствие |
| --- | --- |
| 00:00–05:59 | Доброй ночи |
| 06:00–11:59 | Доброе утро |
| 12:00–17:59 | Добрый день |
| 18:00–23:59 | Добрый вечер |

Переменная `$welcome` выводится в `<h1>` через краткую запись `<?= $welcome ?>`. Ветка `else` задаёт «Доброй ночи» как запасное значение. `date_default_timezone_set('Asia/Qyzylorda')` задаёт местный часовой пояс для правильного приветствия.

## Как объяснить преподавателю

«В начале PHP-файла я получаю текущие день, месяц, год и час. Дату собираю из переменных, а год в подвале теперь обновляется автоматически. По текущему часу `if / elseif / else` выбирает приветствие, которое вставляется в заголовок. Для Open Server с PHP 8.3 я также учёл кодировку русского месяца и предупреждение об устаревшей `strftime()`.»
